# Public Kit 0.1.0-rc.1

First preview release by Ievgen Kylymnyk.

The main artifact is **SKILL.md**: a self-contained skill for Codex and Claude Code, including an analytical workflow, 27 public-source guides, output templates, a synthetic worked example, attribution and the MIT licence. It needs no adjacent reference files or scripts.

The companion website provides the direct file download, searchable directory and an interactive version of the worked example. Its JSON export records the selected budget, weight, equation, inputs and results.

Validation covers the skill format, complete source-directory coverage, worked calculations, changing priorities, budget constraints, ties, invalid inputs, exact published-file identity and local documentation links. Browser checks cover the responsive layout, source filters and model controls.

This preview does not claim measured effectiveness across clients or fresh availability and terms checks for every provider. Source access labels are a dated catalogue snapshot. The example's invented scores are for teaching, not policy recommendations.

The skill credits the independent Civic Analytics Agent Workflow as inspiration. Public Kit has no institutional endorsement.
