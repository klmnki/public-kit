# Global Data Kit 0.3.2-rc.1

18 free institutional data guides in one self-contained [SKILL.md](../SKILL.md). This preview shortens the file and tightens how the assistant handles evidence.

## Changes

- Reduced the skill from 4,684 to 3,422 words, keeping all 18 source guides and request examples.
- Added a rule to identify processed extracts and disclose missing original responses where that limits verification.
- Clarified that dated examples guide requests; answers must use the current task's retrieved or supplied evidence.
- Published all 15 comparative Codex answers, the fixed rubric and grading evidence. The final file scored 48/48 and the baseline 47/48. Both got the main calculations right; this small test does not prove general superiority. [Full report](EVALUATION.md).
- Clarified metadata-only checks for GeoHub, HDX and WaPOR. Their numerical data or raster assets were not retrieved in those checks.

The compact page, 18 source tiles and three saved analyses remain. The About panel links to the comparison report. The site download and release asset contain the same single skill file.

## Verification

Release checks cover the 33 existing offline tests, fixed evaluation-fixture integrity, skill format, JavaScript syntax, build, local links, private-material patterns, exact skill bytes and checksum. Publication checks verify the downloaded skill on both public sites.

## Limits

Comparative tests used saved evidence in Codex. Claude Code, live retrieval and automatic activation were not tested in that comparison. Earlier OECD numerical queries failed; NASA FIRMS and Copernicus authenticated retrievals remain untested. Example data are dated snapshots with no automatic refresh.
