Sources and
access requirements
Each guide includes a request or download route, the fields to inspect and the limits that matter. All routes are free within their provider’s terms; two require free credentials.
Original routes checked 10 October 2026: 13 services returned data or metadata. On 11 October, the ILOSTAT, PIP and monthly Eurostat examples returned observations. OECD’s data request failed. NASA FIRMS and Copernicus were checked against documentation and were not tested with credentials. This is a dated check, not an availability guarantee.

WHY I MADE THIS
About Public Kit
In my GenAI Builders work, the starting point is an everyday question or decision. A small prototype becomes more useful when it can draw on relevant data. Public Kit collects the source instructions for that step, so someone can use them in a conversation with a coding agent.
By Ievgen Kylymnyk. The idea of sharing the workflow as a skill was inspired by Civic Analytics Agent Workflow. Public Kit is independently written and has no institutional endorsement.
