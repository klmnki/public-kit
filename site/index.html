01 / THE METHODQUESTION → EVIDENCE → USE

Start with the question.
Build what helps answer it.

The file gives your agent a way to work through public-interest questions. Use a short source check for a small request, or go further when the decision calls for it.

A / ANALYTICS

Understand a pattern.

Align definitions and denominators. Preserve missing values. Explain what a comparison can support.

“Compare population trends using the latest common observed period.”

B / DECISIONS & SCENARIOS

Explore a choice.

Make criteria, constraints and assumptions explicit. Change an input and see whether the conclusion holds.

“Which assumptions change the ordering of these options?”

C / WORKFLOWS

Make it repeatable.

Keep sources and calculations traceable. Define refresh steps, validation and what happens when data fails.

“Design a research watch with deduplication and evidence appraisal.”
